# 智慧製造邊緣 AI 檢測方案簡報範例 (Smart Factory Deck Fixture)

本範例為 3 頁工業級邊緣運算與表面瑕疵檢測架構簡報的驗證樣本 (Regression Fixture)。

## 包含檔案
- `deck_sample.html`: 3 頁標準 HTML 投影片源碼 (16:9, `.slide-container` 佈局)

## 轉換命令
使用 `html2slides` 工具執行轉換：

```bash
html2slides examples/enterprise_ai_deck/deck_sample.html -o output/enterprise_deck.pptx
```
